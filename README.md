One line, 99 characters — a code review comment that approves a pull request with quiet existential dread:

> Approved at 3 a.m. The code is fine. I am the part of this review that is no longer under warranty.

`main.py` keeps the line as data and writes it to `/output/entry.txt` only after the 1–140 character, single-line gate checks out at run time.
